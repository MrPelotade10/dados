Sobre o Projeto

Este projeto tem como objetivo analisar um conjunto de dados de jogos eletrônicos, identificando padrões de vendas, gêneros mais populares, plataformas mais utilizadas e empresas com maior participação no mercado.

Base de Dados

16.291

Jogos

11

Variáveis

1980-2020

Período

Principais Resultados

  • Action é o gênero mais frequente.
  • DS e PS2 são as plataformas com mais jogos.
  • Electronic Arts é a publicadora com mais títulos.
  • Wii Sports é o jogo mais vendido do dataset.

Visualizações do ObservableHQ

Conclusão

A análise permitiu compreender a evolução do mercado de jogos eletrônicos, identificando os gêneros mais populares, plataformas predominantes e títulos com maior sucesso comercial.
